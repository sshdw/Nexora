# Химия · 9-сынып конспектісі

**Бейорганикалық қосылыстардың негізгі кластары** — оксидтер · негіздер · қышқылдар · тұздар

> НИШ 9-сынып бағдарламасы: 9.1В Периодтық жүйе заңдылықтары · 9.4 Бейорганикалық қосылыстардың негізгі кластары

## 0. Ең бастысы — 10 ереже

- Период нөмірі = электрон қабаттарының (энергетикалық деңгейлердің) саны.
- Топ нөмірі = сыртқы қабаттағы электрон саны (1–2 топ үшін). 13–18 топ үшін: топ нөмірі − 10.
- Ядро заряды Z = протон саны = реттік нөмір. Нейтрон саны: **N = Ar − Z**.
- Валенттік электрондар — сыртқы қабаттың электрондары; элементтің қасиетін анықтайды.
- **Топ бойынша жоғарыдан төмен:** радиус ↑, металдық қасиет ↑, негіздік қасиет ↑, тотықтырғыш қабілет ↓.
- **Период бойынша солдан оңға:** радиус ↓, металдық ↓, бейметалдық ↑, қышқылдық ↑, тотықтырғыш ↑.
- Оксид — екі элементтен тұратын, біреуі оттек (O⁻²) қосылыс.
- Негіз = Me(OH)ₙ, қышқыл = HₙR, тұз = MeₙRₘ (металл + қышқылдық қалдық).
- Барлық реакцияларда: **зат массасы сақталады → теңдеуді теңестір**.
- Реакция жүру шарты: тұнба ↓, газ ↑ немесе су түзілуі.

## 1. Периодтық жүйе заңдылықтары

Менделеев кестесі — элементтердің ядро зарядының өсу ретімен орналасуы. Қасиеттер ядро зарядына тәуелді периодты түрде өзгереді.

### 1.1. Атом құрылысы бойынша есептеу

```
Реттік нөмір Z = протон саны = электрон саны
Нейтрон саны:  N = Ar − Z
Массалық сан:  Ar = Z + N
Электрондық қабаттар: 2, 8, 18, 32 (сыртқы қабатта ең көбі 8)
```

Мысал: ³⁵Cl → Z = 17, N = 35 − 17 = 18, электрондар 2, 8, 7 → 3-период, VII топ.

### 1.2. Топ және период бойынша өзгерістер

| Қасиет | Топ бойынша (жоғарыдан төмен) | Период бойынша (солдан оңға) |
|---|---|---|
| Ядро заряды | артады | артады |
| Атом радиусы | артады | кемиді |
| Металдық қасиет | артады | кемиді |
| Бейметалдық қасиет | кемиді | артады |
| Тотықтырғыш қабілет | кемиді | артады |
| Тотықсыздандырғыш қабілет | артады | кемиді |
| Оксидтердің негізділігі | артады | кемиді |
| Оксидтердің қышқылдығы | кемиді | артады |
| Балқу / қайнау температурасы | металдарда кемиді, бейметалдарда артады | артады |

### 1.3. Жоғары оксидтер мен сутекті қосылыстар

| Топ | Жоғары оксид | Оксид сипаты | Сутекті қосылыс |
|---|---|---|---|
| I | R₂O | негіздік | — |
| II | RO | негіздік | — |
| III | R₂O₃ | екідайлы | — |
| IV | RO₂ | қышқылдық | RH₄ |
| V | R₂O₅ | қышқылдық | RH₃ |
| VI | RO₃ | қышқылдық | RH₂ |
| VII | R₂O₇ | қышқылдық | RH |

### 1.4. Тотығу дәрежесін қою ережелері

- Қарапайым затта (O₂, Fe, S) — **0**.
- Оттек — әдетте **−2** (H₂O₂-де −1, OF₂-де +2).
- Сутек — металдармен **−1**, бейметалдармен **+1**.
- Бір атомды ионда тотығу дәрежесі = ион заряды (Na⁺ → +1).
- Барлық атомдардың қосындысы: бейтарап молекулада **0**, күрделі ионда — ион заряды.
- Топ нөмірі: ең жоғары тотығу дәрежесі = топ нөмірі; ең төменгі = топ нөмірі − 8.

```
H₂SO₄: 2·(+1) + x + 4·(−2) = 0  →  x = +6  (S)
KMnO₄: +1 + x + 4·(−2) = 0      →  x = +7  (Mn)
Na₂Cr₂O₇: 2·(+1) + 2x + 7·(−2) = 0 → x = +6  (Cr)
NH₄⁺: x + 4·(+1) = +1          →  x = −3  (N)
```

> ⚠️ **Жоғары оксидті топ нөмірінен шығару: оттегі саны = (8 − топ нөмірі) / 2. Мысалы VII топ: (8 − 7) / 2 → R₂O₇; V топ: (8 − 5) / 2 → R₂O₅.**

## 2. Оксидтер

**Оксид** — екі элементтен тұратын, біреуі оттек (тотығу дәрежесі −2) болатын күрделі зат. Оксид емес: OF₂, H₂O₂ (пероксид), O₂, O₃.

### 2.1. Жіктелуі

| Түрі | Құрамы / мысалдар | Негізгі қасиеті |
|---|---|---|
| Негізгі | MeO, Me₂O — Na₂O, K₂O, CaO, MgO, CuO, FeO, BaO | негіз түзеді; қышқылмен, қышқылдық оксидпен әрекеттеседі |
| Қышқылдық | бейметалл оксидтері: CO₂, SO₂, SO₃, P₂O₅, N₂O₅, SiO₂; жоғары дәрежелі металдар: CrO₃, Mn₂O₇ | қышқыл түзеді; сілтімен, негізгі оксидпен әрекеттеседі |
| Екідайлы | ZnO, BeO, Al₂O₃, Cr₂O₃, PbO, SnO, MnO₂ | қышқылмен де, сілтімен де әрекеттеседі |
| Бейтарап | CO, NO, N₂O, SiO | тұз түзбейді, қышқыл/негіз қасиеті жоқ |

### 2.2. Химиялық қасиеттері

**Негізгі оксидтер:**

```
CaO + H₂O → Ca(OH)₂
CaO + 2HCl → CaCl₂ + H₂O
CaO + CO₂ → CaCO₃
Na₂O + SO₃ → Na₂SO₄
CuO + H₂ →(t) Cu + H₂O   (тотықсыздану)
```

**Қышқылдық оксидтер:**

```
SO₃ + H₂O → H₂SO₄
CO₂ + H₂O ⇄ H₂CO₃   (әлсіз, тұрақсыз)
SO₂ + 2NaOH → Na₂SO₃ + H₂O
CO₂ + CaO → CaCO₃
CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O   (әк суы лайланады — CO₂-ге сынақ)
```

**Екідайлы оксидтер:**

```
ZnO + 2HCl → ZnCl₂ + H₂O   (қышқылмен — негіз сияқты)
ZnO + 2NaOH + H₂O → Na₂[Zn(OH)₄]   (сілтімен — қышқыл сияқты)
Al₂O₃ + 6HCl → 2AlCl₃ + 3H₂O
Al₂O₃ + 2NaOH + 3H₂O → 2Na[Al(OH)₄]
```

### 2.3. Алынуы

- Металдың / бейметалдың оттекте жануы: 2Ca + O₂ → 2CaO;  S + O₂ → SO₂
- Тұздардың термиялық ыдырауы: CaCO₃ →(t) CaO + CO₂↑
- Негіздердің ыдырауы: Cu(OH)₂ →(t) CuO + H₂O
- Сутегімен / көміртегімен тотықсыздану: CuO + H₂ → Cu + H₂O

## 3. Негіздер

**Негіз** — металл атомы мен бір немесе бірнеше гидроксид тобынан (−OH) тұратын күрделі зат. OH тобының саны металдың валенттілігіне тең.

### 3.1. Жіктелуі

| Белгісі | Түрлері | Мысалдар |
|---|---|---|
| Ерігіштігі | еритін (сілтілер) / ерімейтін | NaOH, KOH, Ca(OH)₂, Ba(OH)₂ / Cu(OH)₂, Fe(OH)₃, Mg(OH)₂ |
| Қышқылдығы | бірқышқылды / екіқышқылды / үшқышқылды | NaOH / Ca(OH)₂, Ba(OH)₂ / Fe(OH)₃, Al(OH)₃ |
| Күші | күшті / әлсіз | NaOH, KOH, Ca(OH)₂ / NH₃·H₂O, Cu(OH)₂, Fe(OH)₃ |
| Ерекше | екідайлы негіздер | Zn(OH)₂, Al(OH)₃, Be(OH)₂, Cr(OH)₃ |

**Аталуы:** металл атауы + «гидроксиді»: NaOH — натрий гидроксиді, Ca(OH)₂ — кальций гидроксиді, Fe(OH)₃ — темір(III) гидроксиді. Ерітіндісі — сілті, «сілтілі орта» (pH > 7).

### 3.2. Химиялық қасиеттері (4 негізгі)

```
1) + қышқыл (нейтралдау):  NaOH + HCl → NaCl + H₂O
2) + қышқылдық оксид:      2KOH + CO₂ → K₂CO₃ + H₂O
3) + тұз (екеуі де еритін болса):  2NaOH + CuSO₄ → Cu(OH)₂↓ + Na₂SO₄
4) ерімейтін негіз қыздырғанда:    Cu(OH)₂ →(t) CuO + H₂O
```

Қосымша мысалдар:

```
FeCl₃ + 3KOH → Fe(OH)₃↓ + 3KCl   (қоңыр тұнба)
Al(OH)₃ + 3HCl → AlCl₃ + 3H₂O   (негіз ретінде)
Al(OH)₃ + NaOH → Na[Al(OH)₄]   (қышқыл ретінде — екідайлы)
Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O   (әк суы)
```

### 3.3. Алынуы

- Белсенді металл + су: 2Na + 2H₂O → 2NaOH + H₂↑
- Негізгі оксид + су: CaO + H₂O → Ca(OH)₂
- Тұз + сілті: CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄
- Ерімейтін негіздер тек ерітіндідегі реакциямен алынады (MeO + H₂O реакциясы жүрмейді).

## 4. Қышқылдар

**Қышқыл** — сутегі атомдарын (H⁺) металл атомдарына немесе катиондарға бере алатын күрделі зат. Құрамы: H + қышқылдық қалдық.

### 4.1. Жіктелуі

| Белгісі | Түрлері | Мысалдар |
|---|---|---|
| Құрамы | оттекті / оттексіз | H₂SO₄, HNO₃, H₃PO₄ / HCl, H₂S, HBr |
| Негіздігі | бір / екі / үш негізді | HCl, HNO₃ / H₂SO₄, H₂CO₃, H₂S / H₃PO₄ |
| Күші | күшті / әлсіз | HCl, HBr, HI, HNO₃, H₂SO₄ / H₂CO₃, H₂SiO₃, H₂S |
| Ұшпалығы | ұшпа / ұшпайтын | HCl, HNO₃ / H₂SO₄, H₃PO₄ |
| Тұрақтылығы | тұрақты / тұрақсыз | H₂SO₄ / H₂CO₃ → CO₂↑ + H₂O |

**Аталуы:** оттексіз — «...сутек қышқылы»: HCl — хлорсутек қышқылы, H₂S — күкіртсутек қышқылы. Оттекті — элемент атауы + «қышқылы»: H₂SO₄ — күкірт қышқылы, H₂SO₃ — күкіртті қышқыл, HNO₃ — азот қышқылы, HNO₂ — азотты қышқыл, H₂CO₃ — көмір қышқылы, H₃PO₄ — ортофосфор қышқылы.

### 4.2. Химиялық қасиеттері

```
1) + металл (H-қа дейінгі):  Zn + 2HCl → ZnCl₂ + H₂↑
2) + негізгі оксид:            CuO + H₂SO₄ → CuSO₄ + H₂O
3) + негіз (нейтралдау):        NaOH + HNO₃ → NaNO₃ + H₂O
4) + тұз:                      CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑
5) + екідайлы оксид/негіз:      ZnO + 2HNO₃ → Zn(NO₃)₂ + H₂O
```

Сапалық (айыру) реакциялар:

```
HCl + AgNO₃ → AgCl↓ + HNO₃   (ақ ірімшік тәрізді тұнба — Cl⁻-ке сынақ)
H₂SO₄ + BaCl₂ → BaSO₄↓ + 2HCl   (ақ тұнба — SO₄²⁻-ке сынақ)
H₂CO₃ → CO₂↑ + H₂O,  CO₂ + Ca(OH)₂ → CaCO₃↓ + H₂O
```

> ⚠️ **Сұйытылған қышқылдар H-қа дейінгі металдармен әрекеттеседі (K, Ca, Na, Mg, Al, Zn, Fe, Ni, Sn, Pb). Cu, Ag, Au, Hg — әрекеттеспейді.**

### 4.3. Индикаторлар

| Индикатор | Қышқылдық орта | Бейтарап | Сілтілік орта |
|---|---|---|---|
| Лакмус | қызыл | күлгін | көк |
| Метилоранж | қызғылт | қызғылт сары | сары |
| Бромтимол көк | сары | жасыл | көк |
| Фенолфталеин | түссіз | түссіз | таңқурай |

## 5. Тұздар

**Тұз** — металл катионы мен қышқылдық қалдық анионынан тұратын күрделі зат (мысалы NaCl = Na⁺ + Cl⁻).

### 5.1. Тұздардың түрлері

| Түрі | Анықтамасы | Мысалдар |
|---|---|---|
| Орташа (бейтарап) | қышқылдың барлық H атомы металмен алмасқан | NaCl, K₂SO₄, CaCO₃, AlCl₃, Na₃PO₄ |
| Қышқылдық | қышқылдық қалдықта H атомы қалған | NaHSO₄, NaHCO₃, Ca(HCO₃)₂, KH₂PO₄, Na₂HPO₄ |
| Негіздік | құрамында OH тобы қалған | Mg(OH)Cl, Cu(OH)NO₃, Al(OH)₂Cl, Bi(OH)₂NO₃ |
| Қос тұз | екі түрлі катион (немесе анион) | KAl(SO₄)₂, (NH₄)₂Fe(SO₄)₂, NaKCO₃ |
| Кристаллогидрат | құрамында кристалдану суы бар | CuSO₄·5H₂O (мыс купоросы), Na₂CO₃·10H₂O |

**Алыну жолдары:**

```
Қышқылдық тұз: артық қышқылмен — NaOH + H₂SO₄(арт.) → NaHSO₄ + H₂O
Негіздік тұз: артық негізбен — Mg(OH)₂ + HCl → Mg(OH)Cl + H₂O
Орташа тұз: натрий гидроксиді + артық қышқыл — 2NaOH + H₂SO₄ → Na₂SO₄ + 2H₂O
```

### 5.2. Аталуы (халықаралық номенклатура)

Алдымен анион, сосын катион аталады: NaCl — **натрий хлориді**, CaSO₄ — **кальций сульфаты**, Fe₂(SO₄)₃ — **темір(III) сульфаты**, NaHCO₃ — **натрий гидрокарбонаты**, NaHSO₄ — **натрий гидросульфаты**, Mg(OH)Cl — **магний гидроксохлориді**.

| Анион | Атауы | Анион | Атауы |
|---|---|---|---|
| Cl⁻ | хлорид | CO₃²⁻ | карбонат |
| S²⁻ | сульфид | HCO₃⁻ | гидрокарбонат |
| SO₄²⁻ | сульфат | PO₄³⁻ | фосфат |
| SO₃²⁻ | сульфит | SiO₃²⁻ | силикат |
| NO₃⁻ | нитрат | MnO₄⁻ | перманганат |
| NO₂⁻ | нитрит | Cr₂O₇²⁻ | бихромат |

### 5.3. Химиялық қасиеттері

| Реакция | Шарты / белгісі | Мысал |
|---|---|---|
| Тұз + металл | металл тұздағы металдан белсенді болуы керек | Fe + CuSO₄ → FeSO₄ + Cu |
| Тұз + сілті | екеуі де еритін, тұнба түзіледі | CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄ |
| Тұз + қышқыл | тұнба, газ немесе су түзіледі | Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑ |
| Тұз + тұз | екеуі де еритін, тұнба түзіледі | BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl |
| Тұз + негізгі оксид | қышқылдық оксидпен: CaO + CO₂ → CaCO₃ | CaO + SiO₂ → CaSiO₃ |

### 5.4. Тұздардың алынуы (7 әдіс)

```
1) Металл + бейметалл:        2Na + Cl₂ → 2NaCl
2) Металл + қышқыл:           Zn + 2HCl → ZnCl₂ + H₂↑
3) Негіз + қышқыл:            Ca(OH)₂ + 2HNO₃ → Ca(NO₃)₂ + 2H₂O
4) Негізгі оксид + қышқылдық оксид:  CaO + CO₂ → CaCO₃
5) Негіз + қышқылдық оксид:   2NaOH + SO₃ → Na₂SO₄ + H₂O
6) Металл + тұз:              Fe + CuSO₄ → FeSO₄ + Cu
7) Тұз + тұз (немесе тұз + сілті):  AgNO₃ + NaCl → AgCl↓ + NaNO₃
```

### 5.5. Ерігіштік ережелері (қысқаша)

- Барлық **нитраттар**, сілтілік металдар мен аммоний тұздары — **ериді**.
- **Хлоридтер** ериді, тек AgCl, PbCl₂ — ерімейді.
- **Сульфаттар** ериді, тек BaSO₄, PbSO₄ — ерімейді, CaSO₄ — нашар ериді.
- **Карбонаттар, фосфаттар, силикаттар, сульфидтер** — тек Na, K, NH₄ тұздары ериді.
- Сілтілер: NaOH, KOH, LiOH, Ca(OH)₂, Ba(OH)₂, Sr(OH)₂ — ериді.

### 5.6. Күнделікті қолданылатын тұздар

| Формуласы | Химиялық атауы | Күнделікті атауы / қолданылуы |
|---|---|---|
| NaCl | натрий хлориді | ас тұзы; консервілеу, тағам |
| Na₂CO₃ | натрий карбонаты | сода (кір жуу содасы) |
| NaHCO₃ | натрий гидрокарбонаты | азық-түлік содасы, дәрі |
| CaCO₃ | кальций карбонаты | әктас, мәрмәр, бор, цемент |
| CuSO₄·5H₂O | мыс(II) сульфатының кристаллогидраты | мыс купоросы (өсімдікті қорғау) |
| KMnO₄ | калий перманганаты | марганцовка (антисептик) |
| CaSO₄·2H₂O | кальций сульфатының кристаллогидраты | гипс |
| Na₂SO₄·10H₂O | натрий сульфатының кристаллогидраты | глаубер тұзы |

## 6. Генетикалық байланыс

Бір элемент қосылыстарының айналымы — «генетикалық қатар»:

```
Металл:     Me → MeO → Me(OH)ₙ → тұз
Бейметалл:  бейметалл → қышқылдық оксид → қышқыл → тұз
```

Мысал (кальций қатары):

```
1) 2Ca + O₂ → 2CaO
2) CaO + H₂O → Ca(OH)₂
3) Ca(OH)₂ + CO₂ → CaCO₃↓ + H₂O
4) CaCO₃ + 2HCl → CaCl₂ + H₂O + CO₂↑
```

Мысал (күкірт қатары):

```
1) S + O₂ → SO₂        2) 2SO₂ + O₂ →(t, кат.) 2SO₃
3) SO₃ + H₂O → H₂SO₄   4) H₂SO₄ + 2NaOH → Na₂SO₄ + 2H₂O
```

## 7. Иондық теңдеулер

- Күшті электролиттер ионға ыдырайды, әлсіздер, тұнба, газ, су — жазылмайды.
- Толық иондық теңдеу → қысқартылған иондық теңдеу.

```
NaOH + HCl → NaCl + H₂O
Na⁺ + OH⁻ + H⁺ + Cl⁻ → Na⁺ + Cl⁻ + H₂O
Қысқаша:  H⁺ + OH⁻ → H₂O   (нейтралдау)

BaCl₂ + Na₂SO₄ → BaSO₄↓ + 2NaCl
Қысқаша:  Ba²⁺ + SO₄²⁻ → BaSO₄↓
```

## 8. Зертханалық тәжірибелер (қорытынды)

| Тәжірибе | Реактив | Белгісі | Теңдеу |
|---|---|---|---|
| Негізгі оксид | CaO + H₂O | ертінді лайланады, жылу бөлінеді | CaO + H₂O → Ca(OH)₂ |
| Сілті + индикатор | фенолфталеин | таңқурай түс | — |
| Қышқыл + индикатор | лакмус / метилоранж | қызыл / қызғылт | — |
| Екідайлы оксид | ZnO + HCl / NaOH | тұнба ериді | ZnO + 2HCl → ZnCl₂ + H₂O |
| Негіз + қышқыл | NaOH + HCl | жылу, түс өзгермейді | NaOH + HCl → NaCl + H₂O |
| Ерімейтін негіз | CuSO₄ + NaOH | көк тұнба Cu(OH)₂ | CuSO₄ + 2NaOH → Cu(OH)₂↓ + Na₂SO₄ |
| Карбонат + қышқыл | Na₂CO₃ + HCl | газ көпіршіктері (CO₂) | Na₂CO₃ + 2HCl → 2NaCl + H₂O + CO₂↑ |
| Сульфатқа сынақ | BaCl₂ | ақ тұнба BaSO₄ | BaCl₂ + H₂SO₄ → BaSO₄↓ + 2HCl |

## 9. Жиі жіберілетін қателер

| Қате | Дұрыс |
|---|---|
| «CaO + H₂O → Ca(OH)₂↓» деп тұнба деп жазу | Ca(OH)₂ нашар ериді, бірақ сілті — тұнба ↓ қойылмайды |
| Cu + HCl → CuCl₂ + H₂ деп жазу | Cu — H-тан кейінгі металл, сұйытылған қышқылмен әрекеттеспейді |
| Na₂O + H₂O → NaOH (теңестірілмеген) | Na₂O + H₂O → 2NaOH |
| Al(OH)₃-ті тек негіз деп санау | Al(OH)₃ екідайлы: қышқылмен де, сілтімен де әрекеттеседі |
| «NaCl — натрий хлор» деп атау | NaCl — натрий хлориді (анион бірінші) |
| Екі еритін тұздан газ шығады деп күту | Тұз + тұз реакциясы тек тұнба түзілгенде жүреді |
| Иондық теңдеуде тұнбаны ионға жіктеу | Тұнба, газ, су, әлсіз электролит — жіктелмейді |
| Топ нөмірін сыртқы электрон саны деп алу (13–18 топ) | 13–18 топ: сыртқы электрон = топ нөмірі − 10 |

## 10. Мини-тест (өзіңді тексер)

1. Период нөмірі нені көрсетеді?
2. Топ нөмірі нені көрсетеді (1–2 топ; 13–18 топ)?
3. Период бойынша солдан оңға атом радиусы қалай өзгереді?
4. Мына оксидтерді жікте: Na₂O, CO₂, ZnO, CO, CrO₃.
5. Қай оксид екідайлы: CaO, Al₂O₃, SO₃, N₂O?
6. NaOH, Cu(OH)₂, Al(OH)₃ — қайсысы сілті, қайсысы екідайлы?
7. H₂SO₄, H₂CO₃, HCl, H₃PO₄ — негіздігі бойынша ата.
8. NaHCO₃, Mg(OH)Cl, KAl(SO₄)₂ — тұздың қай түрі?
9. Аяқта: BaCl₂ + Na₂SO₄ → ...
10. Аяқта: ZnO + NaOH + H₂O → ...

### Жауаптары

- 1) Электрон қабаттарының санын.  2) Сыртқы қабаттағы электрон санын (13–18 топ: топ нөмірі − 10).  3) Кемиді.
- 4) Негізгі: Na₂O; қышқылдық: CO₂, CrO₃; екідайлы: ZnO; бейтарап: CO.
- 5) Al₂O₃.  6) NaOH — сілті; Cu(OH)₂ — ерімейтін негіз; Al(OH)₃ — екідайлы.
- 7) H₂SO₄ — екінегізді, H₂CO₃ — екінегізді, HCl — бірнегізді, H₃PO₄ — үшнегізді.
- 8) NaHCO₃ — қышқылдық, Mg(OH)Cl — негіздік, KAl(SO₄)₂ — қос тұз.
- 9) BaSO₄↓ + 2NaCl.  10) Na₂[Zn(OH)₄].

> ⚠️ **Емтиханда: теңдеуді жаз → теңестір → тұнба/газ белгісін қой → иондық түрін көрсет. Әр тапсырмада «не сұралды?» деген сұраққа жауап беріп отыр.**
